Featured Projects

01

RoboDog — Quadruped Robot

Custom PCB, from schematic to routed board to walking hardware.

An 8-servo quadruped built around a PCB I designed myself in KiCad — not a breadboard prototype. The board integrates an ESP32-WROOM, a PCA9685 PWM driver for all 8 servo channels, dual buck converters for clean regulated power, and a decoupling network sized to keep every servo's power rail stable under load. Schematic-to-layout ownership: four functional sections (power, MCU, decoupling, servo connectors), routed and fabricated.

ESP32-WROOM PCA9685 KiCad PCB Design Power Electronics C++
02

Embedded Job Search Automation

A multi-source job aggregator that doesn't trust "Entry level" tags.

LinkedIn's "Entry level" tag is unreliable — plenty of roles tagged that way actually want 2–8 years once you read the JD. I built a pipeline that scrapes LinkedIn, Indeed, Naukri, direct company career pages, and Greenhouse/Lever's public APIs, then reads each job's real title and description to reject senior-disguised-as-entry postings before they're ever saved — not just keyword-matched, actually experience-filtered. Runs on a schedule, pings my phone on Telegram when it's done, and I review results in a Streamlit dashboard instead of a terminal.

Python Playwright SQLite Streamlit Telegram Bot API
